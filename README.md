"From this project , I learnt about the binomial distribution and poisson distribution and how it is used to calculate the probability of getting a specific number of sucesses in a fixed number of independent trials. I understood the importance of the number of trials((n)),probability of success (p) , and target successes (k) in calculating probabilities . I also learned how to calculate the mean variance , standard deviation, and other statistical measures of a binomial distribution . By developing this interactive application , I gained practical knowledge of how mathematical formulas can be implemented in a web interface using programming . the graphs, probability tables , and step-by-step calculations helped me understand the concepts clearly . I also learned how probability are calculated and how probability distributions can be applied to real world problems , such as tracking errors in machine learning models . Overall, this project helped me connect theoretical concepts from probability and statistics with practical application in AIML"
